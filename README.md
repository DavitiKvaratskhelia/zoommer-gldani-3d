მასშტაბი: **1 ერთეული = 1 მეტრი**, Y ღერძი ზემოთ.

## გახსნა

- **branch-viewer.html** — უბრალოდ გახსენით ორჯერ დაწკაპუნებით (Chrome, Edge, Firefox, Safari).
  Three.js და მოდელის გეომეტრია ფაილშივეა: **ინტერნეტი და ლოკალური სერვერი არ სჭირდება**.
  საჭიროა WebGL-ის მხარდაჭერა (ნებისმიერი თანამედროვე ბრაუზერი).
- **branch-model.glb** — Blender: *File → Import → glTF 2.0*; Windows-ზე იხსნება „3D Viewer“-შიც.
  ერთეული — მეტრი. სათავე (0,0,0) — ორი მინის ფასადის შიდა კუთხე იატაკის დონეზე;
  X — ფასადი A-ს გასწვრივ, Z — ფასადი B-ს გასწვრივ.

ობიექტზე დაჭერისას ბარათში ჩანს სახელი, კოდი (ZF-…) და ზომები. ყოველ ზომას აქვს ნიშანი:

- **PDF** — რიცხვით მითითებულია PDF-ში (ან ზუსტად გამოითვლება მითითებული ზომების ჯამით);
- **≈ ნახაზიდან** — რიცხვი PDF-ში არ არის, გაზომილია ნახაზიდან მასშტაბით;
- **ვარაუდი** — PDF-ში არ არის, აღებულია გონივრული მნიშვნელობა.

ზომების რეჟიმში მუქი უწყვეტი ხაზი = PDF-ში მითითებული, ნარინჯისფერი წყვეტილი „≈“ = გაზომილი/სავარაუდო.

## ვიზუალური სტილი („დიორამა“)

სანახავი აჩვენებს მოდელს მუქ ფონზე, მუქ კვარცხლბეკზე, რომლის ქვეშაც თბილი სანათები
მიწაზე შუქის ლაქებს ქმნის; შიგნით — რბილი თბილი განათება, არეკვლები და კონტაქტური
ჩრდილები (ambient occlusion). კონტაქტური ჩრდილები ითვლება მხოლოდ კამერის გაჩერებისას —
ტრიალისა და ზუმის დროს გამოსახულება ცოტა „ბრტყელდება“, სამაგიეროდ მართვა რბილი რჩება.
კვარცხლბეკი, მიწა, შუქის ლაქები და სანათები მხოლოდ წარმოდგენის ნაწილია და **GLB-ში არ შედის**.
ფერები/განათება: `src/viewer.js` (განყოფილებები „რენდერერი“, „კვარცხლბეკი…“, „განათება“).

## კოდის შეცვლა და ხელახლა აწყობა

საჭიროა Node.js 18+.

```bash
npm install
```

```bash
npm run build
```

`npm run build` ხელახლა ქმნის ორივე ფაილს: `dist/branch-viewer.html` და `dist/branch-model.glb`
(და ამოწმებს GLB-ს: ჯგუფები, მეშების რაოდენობა, საზღვრები მეტრებში).
ყველა ზომა, სიმაღლე, სისქე, ფერი და ავეჯის პოზიცია არის `src/config.js`-ში — მაგალითად,
ტიხრების სიმაღლე: `H.partition`, ვიტრინის სიმაღლე: `HU`, ავეჯი: `FURNITURE` სია.
სანახავის ლოკალურად გაშვება (არ არის აუცილებელი): `npm run serve` → http://localhost:5179
